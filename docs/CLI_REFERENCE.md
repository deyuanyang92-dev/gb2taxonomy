# Command-line reference (g2t v0.06)

Generated by `scripts/make_cli_reference.py` from each command's `--help`; README.md and USAGE.en.md explain the options in context.

## g2t

```text
usage: g2t [-h] [--version] -i INPUT [INPUT ...] -o OUTPUT
           [--stream | --no-stream] [--batch] [--max_tasks MAX_TASKS]
           [--resume] [--quiet] [--skip_extract] [--skip_classify]
           [--no-verify] [--no-screen] [--skip_voucher] [--skip_organize]
           [--skip_reconcile] [--reconcile_min_confidence {high,medium}]
           [--normalize_columns] [--drop_empty_gene_columns]
           [--split_by COLUMN]

GenBank to Taxonomy pipeline: extract -> classify -> voucher -> reconcile ->
organize

options:
  -h, --help            show this help message and exit
  --version             Print the g2t version and exit
  -i, --input INPUT [INPUT ...]
                        GenBank files or directories
  -o, --output OUTPUT   Root output directory
  --stream, --no-stream
                        Stream the extraction step (default; same results,
                        less memory on large inputs)
  --batch               Use batch parallel processing
  --max_tasks MAX_TASKS
                        Max parallel tasks for batch mode
  --resume              Skip steps whose output already exists
  --quiet               No progress messages or final summary (errors are
                        still printed)
  --skip_extract        Skip step 1 (use its output in -o)
  --skip_classify       Skip step 2 (use its output in -o)
  --no-verify           Keep the annotation's rRNA gene types (default: check
                        them against the sequence, step 2b)
  --no-screen           Skip step 5, the contamination / misidentification
                        screen
  --skip_voucher        Skip step 3 (use its output in -o)
  --skip_organize       Skip step 4, the matrix
  --skip_reconcile      Do not merge voucher variants (organize exact-match
                        vouchers only)
  --reconcile_min_confidence {high,medium}
                        Evidence needed to merge voucher variants (default:
                        medium)
  --normalize_columns   Normalize column names (spaces to underscores)
  --drop_empty_gene_columns
                        Leave out gene columns that are empty in every row of
                        the matrix (default: fixed layout)
  --split_by COLUMN     Also write one matrix per value of COLUMN (e.g.
                        Family, Order) into by_<COLUMN>/ with _summary.csv
```

## g2t-download

```text
usage: g2t-download [-h] (-t NAME|TAXID | -a FILE) [-o DIR] [-e ADDR] [-k KEY]
                    [--validate] [--all] [--mito] [--mitogenome] [--gene LIST]
                    [--minlen BP] [--maxlen BP] [--query CLAUSE]
                    [--include-wgs] [--include-mrna] [--include-tsa]
                    [--include-refseq] [--include-large] [--header-only]
                    [--summary-only] [--tag NAME] [--since auto|DATE]
                    [--store FILE | --no-store] [-n] [--report] [-b N] [-w N]
                    [-q]

Download GenBank records of a taxon from NCBI.

options:
  -h, --help            show this help message and exit
  -t, --taxon NAME|TAXID
                        taxon name or NCBI taxid
  -a, --accessions FILE
                        file with one accession per line (or first column of a
                        .csv/.tsv), instead of -t
  -o, --output DIR      output root; records go to DIR/TAG/ (default:
                        <taxon>_gb)
  -e, --email ADDR      e-mail for NCBI (default: $NCBI_EMAIL)
  -k, --api-key KEY     NCBI API key (default: $NCBI_API_KEY, else api_key= in
                        ~/.config/g2t/credentials)
  --validate            parse the batch files with Biopython afterwards

selection (default: marker records, see README):
  --all                 all records, incl. WGS, mRNA and RefSeq
  --mito                mitochondrial records only
  --mitogenome          complete mitochondrial genomes only (>= 10 kb)
  --gene LIST           genes, e.g. COI,18S,28S
  --minlen BP           minimum sequence length (also lifts the 100 kb cap)
  --maxlen BP           maximum sequence length
  --query CLAUSE        extra Entrez clause, e.g. 'Russia[Country]'
  --include-wgs         keep WGS contigs
  --include-mrna        keep mRNA records
  --include-tsa         keep transcriptome shotgun assembly (TSA) contigs
  --include-refseq      keep RefSeq records
  --include-large       keep nuclear records > 100 kb (organelle records are
                        always kept)
  --header-only         record headers only, no sequence (assembly/sequencing
                        notes, references, source); lengths and dates in
                        summary.tsv. For metadata analyses such as
                        g2t-mitostats
  --summary-only        no records: only summary.tsv (accession, length,
                        dates, taxid, title) from esummary; fastest
  --tag NAME            output sub-directory (default: from the selection)

update:
  --since auto|DATE     fetch only records modified since the last run or DATE
                        (YYYY-MM-DD)
  --store FILE          record store (default: OUTPUT/_records.sqlite)
  --no-store            keep records only in the batch files

run:
  -n, --dry-run         report counts and records to fetch; write nothing
  --report              also count records per gene (extra NCBI searches)
  -b, --batch-size N    records per request and batch file (default: 500)
  -w, --workers N       parallel NCBI requests (default: 3; 8 with an API key,
                        which allows 10 requests/s)
  -q, --quiet           no progress output

examples:
  g2t-download -t Polynoidae -o gb                 first download (markers)
  g2t-download -t Polynoidae -o gb --since auto    later: only new or modified records
  g2t-download -t Polynoidae -o gb -n              counts only
  g2t-download -t 46593 -o gb --mitogenome
  g2t-download -t Annelida -o gb --mitogenome --header-only   metadata only (~1/12 of the size)
  g2t-download -t Metazoa -o gb --mitogenome --summary-only    lengths/dates/taxa only, no records
  g2t-download -a my_accessions.txt -o gb                      exactly these records

Re-running skips records already downloaded. Exit status 1 if records failed.
```

```text

                   [-a ASSEMBLY_OUTPUT] [-f FINAL_OUTPUT]
                   [--stream | --no-stream] [--batch] [--max_tasks MAX_TASKS]
                   [--log_interval LOG_INTERVAL]
                   [--metadata_delimiter METADATA_DELIMITER]
                   [--assembly_delimiter ASSEMBLY_DELIMITER]
                   [--final_delimiter FINAL_DELIMITER] [--only_assembly_meta |
                   --only_except_assembly_meta] [--update_taxonomy]
                   [--no_report] [--no_tracking] [--no_recursive]
                   [--if_use_chunksize]

GenBank Metadata Extractor (refactored): 3-strategy Assembly + record tracking

options:
  -h, --help            show this help message and exit
  -i, --input INPUT [INPUT ...]
                        Input GenBank files or directories (default: None)
  -o, --output OUTPUT   Output directory (default: .)
  -m, --metadata-output METADATA_OUTPUT
                        Metadata table (one row per record) (default:
                        metadata.csv)
  -a, --assembly-output ASSEMBLY_OUTPUT
                        Assembly / sequencing data table (default:
                        assembly.csv)
  -f, --final-output FINAL_OUTPUT
                        Metadata and assembly data merged (default: final.csv)
  --stream, --no-stream
                        Stream processing (default; same results, less memory
                        on large inputs) (default: True)
  --batch               Batch mode (parallel) (default: False)
  --max_tasks MAX_TASKS
                        Parallel processes in --batch mode (default: 4)
  --log_interval LOG_INTERVAL
                        Log progress every N records (0 = never) (default:
                        5000)
  --metadata_delimiter METADATA_DELIMITER
                        Column delimiter of the metadata table (default: ,)
  --assembly_delimiter ASSEMBLY_DELIMITER
                        Column delimiter of the assembly table (default: )
  --final_delimiter FINAL_DELIMITER
                        Column delimiter of the merged table (default: ,)
  --only_assembly_meta, -oam
                        Extract only the assembly / sequencing data (default:
                        False)
  --only_except_assembly_meta, -oeam
                        Extract only the metadata (no assembly data) (default:
                        False)
  --update_taxonomy     Update the local ete3 NCBI taxonomy database first
                        (default: False)
  --no_report           Do not write extraction_report.json and the error
                        table (default: False)
  --no_tracking         Do not write the per-record tracking table (default:
                        False)
  --no_recursive        Do not search subdirectories of the inputs (default:
                        False)
  --if_use_chunksize    (Legacy) same as --stream (default: False)
```

## g2t-cite

```text
usage: g2t-cite [-h] -i INPUT [INPUT ...] -o OUTPUT [--mailto MAILTO]
                [--delay DELAY] [-q]

Find the published paper (Crossref) of GenBank records still marked 'Unpublished'.

options:
  -h, --help            show this help message and exit
  -i, --input INPUT [INPUT ...]
                        GenBank files/folders, or g2t tables (.csv/.tsv/.xlsx)
                        with Ref1Journal.. columns
  -o, --output OUTPUT   cite.xlsx (or .csv -> _curate.csv + _candidates.csv)
  --mailto MAILTO       your e-mail for the Crossref polite pool (default:
                        $CROSSREF_MAILTO; none sent otherwise)
  --delay DELAY         seconds between Crossref queries (default 0.2)
  -q, --quiet

examples:
  g2t-cite -i gb/mitogenome-header -o cite.xlsx
  g2t-cite -i final.csv -o cite.xlsx
  g2t-curate -m matrix.xlsx -u cite.xlsx -o curated.xlsx   # apply sheet 'Curate'
  g2t-mitostats -i gb/mitogenome-header -o mito --citations cite.xlsx
```

## g2t-verify

```text
usage: g2t-verify [-h] -i INPUT [INPUT ...] --g2t DIR -o DIR
                  [--models HMM [HMM ...]] [--all] [--min-bp MIN_BP]
                  [--min-cover MIN_COVER] [--cpu CPU] [--no-cache]
                  [--all-models]

g2t-verify: check gene assignments against the sequence itself (rRNA profile HMMs).

options:
  -h, --help            show this help message and exit
  -i, --input INPUT [INPUT ...]
                        GenBank files or folders (with sequences)
  --g2t DIR             output folder of the g2t run on these records
  -o, --output DIR
  --models HMM [HMM ...]
                        your own nucleotide HMM file(s) instead of barrnap 0.9
  --all                 scan every record (default: rRNA, unmatched,
                        conflicted)
  --min-bp MIN_BP       region length that counts as a gene (default 150)
  --min-cover MIN_COVER
                        or this share of the model (default 0.5)
  --cpu CPU             threads (default: all cores)
  --no-cache            do not reuse or store hits (default cache:
                        /root/.cache/g2t/verify_hits.sqlite)
  --all-models          run every model on every record (default: g2t's region
                        first, others if needed)

examples:
  g2t-verify -i gb/markers --g2t out -o verify
  g2t-verify -i gb/markers --g2t out -o verify --models my_rrna.hmm
```

## g2t-screen

```text
usage: g2t-screen [-h] -i INPUT [INPUT ...] --g2t DIR [-o CSV] [--tree]
                  [--taxon TAXON] [--background BACKGROUND]
                  [--background-n BACKGROUND_N] [--iqtree] [--support SUPPORT]

g2t-screen: flag possible contaminated or misidentified sequences, marker by marker.

options:
  -h, --help            show this help message and exit
  -i, --input INPUT [INPUT ...]
                        GenBank files or folders (with sequences)
  --g2t DIR             output folder of the g2t run on these records
  -o, --output CSV      default: <g2t>/organized_genes/screen.csv

phylogenetic screen (gene trees with related families; FAMSA/MAFFT + FastTree/IQ-TREE):
  --tree                also place every sequence in a gene tree with
                        relatives
  --taxon TAXON         the studied family (default: the commonest Family of
                        the records)
  --background BACKGROUND
                        related families, comma separated (default: chosen
                        from NCBI Taxonomy)
  --background-n BACKGROUND_N
                        number of related families (default 6)
  --iqtree              IQ-TREE with 1,000 ultrafast bootstraps (slower)
  --support SUPPORT     branch support needed (default 0.9)
```
