# Command-line reference (g2t 0.0.4)

Generated by `scripts/make_cli_reference.py` from each command's `--help`; README.md and USAGE.en.md explain the options in context.

## g2t

```text
usage: g2t [-h] [--version] -i INPUT [INPUT ...] -o OUTPUT
           [--stream | --no-stream] [--batch] [--max_tasks MAX_TASKS]
           [--resume] [--quiet] [--skip_extract] [--skip_classify]
           [--skip_voucher] [--skip_organize] [--skip_reconcile]
           [--reconcile_min_confidence {high,medium}] [--normalize_columns]
           [--drop_empty_gene_columns] [--split_by COLUMN]

GenBank to Taxonomy pipeline: extract -> classify -> voucher -> reconcile ->
organize

options:
  -h, --help            show this help message and exit
  --version             Print the g2t version and exit
  -i INPUT [INPUT ...], --input INPUT [INPUT ...]
                        GenBank files or directories
  -o OUTPUT, --output OUTPUT
                        Root output directory
  --stream, --no-stream
                        Stream the extraction step (default; same results,
                        less memory on large inputs)
  --batch               Use batch parallel processing
  --max_tasks MAX_TASKS
                        Max parallel tasks for batch mode
  --resume              Skip steps whose output already exists
  --quiet               No progress messages or final summary (errors are
                        still printed)
  --skip_extract        Skip step 1 (use its output in -o)
  --skip_classify       Skip step 2 (use its output in -o)
  --skip_voucher        Skip step 3 (use its output in -o)
  --skip_organize       Skip step 4, the matrix
  --skip_reconcile      Do not merge voucher variants (organize exact-match
                        vouchers only)
  --reconcile_min_confidence {high,medium}
                        Evidence needed to merge voucher variants (default:
                        medium)
  --normalize_columns   Normalize column names (spaces to underscores)
  --drop_empty_gene_columns
                        Leave out gene columns that are empty in every row of
                        the matrix (default: fixed layout)
  --split_by COLUMN     Also write one matrix per value of COLUMN (e.g.
                        Family, Order) into by_<COLUMN>/ with _summary.csv
```

## g2t-download

```text
usage: g2t-download [-h] -t NAME|TAXID [-o DIR] [-e ADDR] [-k KEY]
                    [--validate] [--all] [--mito] [--mitogenome] [--gene LIST]
                    [--minlen BP] [--maxlen BP] [--query CLAUSE]
                    [--include-wgs] [--include-mrna] [--include-tsa]
                    [--include-refseq] [--include-large] [--tag NAME]
                    [--since auto|DATE] [--store FILE | --no-store] [-n]
                    [--report] [-b N] [-w N] [-q]

Download GenBank records of a taxon from NCBI.

options:
  -h, --help            show this help message and exit
  -t NAME|TAXID, --taxon NAME|TAXID
                        taxon name or NCBI taxid
  -o DIR, --output DIR  output root; records go to DIR/TAG/ (default:
                        <taxon>_gb)
  -e ADDR, --email ADDR
                        e-mail for NCBI (default: $NCBI_EMAIL)
  -k KEY, --api-key KEY
                        NCBI API key (default: $NCBI_API_KEY)
  --validate            parse the batch files with Biopython afterwards

selection (default: marker records, see README):
  --all                 all records, incl. WGS, mRNA and RefSeq
  --mito                mitochondrial records only
  --mitogenome          complete mitochondrial genomes only (>= 10 kb)
  --gene LIST           genes, e.g. COI,18S,28S
  --minlen BP           minimum sequence length (also lifts the 100 kb cap)
  --maxlen BP           maximum sequence length
  --query CLAUSE        extra Entrez clause, e.g. 'Russia[Country]'
  --include-wgs         keep WGS contigs
  --include-mrna        keep mRNA records
  --include-tsa         keep transcriptome shotgun assembly (TSA) contigs
  --include-refseq      keep RefSeq records
  --include-large       keep nuclear records > 100 kb (organelle records are
                        always kept)
  --tag NAME            output sub-directory (default: from the selection)

update:
  --since auto|DATE     fetch only records modified since the last run or DATE
                        (YYYY-MM-DD)
  --store FILE          record store (default: OUTPUT/_records.sqlite)
  --no-store            keep records only in the batch files

run:
  -n, --dry-run         report counts and records to fetch; write nothing
  --report              also count records per gene (extra NCBI searches)
  -b N, --batch-size N  records per request and batch file (default: 500)
  -w N, --workers N     parallel NCBI requests (default: 3)
  -q, --quiet           no progress output

examples:
  g2t-download -t Polynoidae -o gb                 first download (markers)
  g2t-download -t Polynoidae -o gb --since auto    later: only new or modified records
  g2t-download -t Polynoidae -o gb -n              counts only
  g2t-download -t 46593 -o gb --mitogenome

Re-running skips records already downloaded. Exit status 1 if records failed.
```

```text
GenBank Metadata Extractor (refactored): 3-strategy Assembly + record tracking

options:

  -i INPUT [INPUT ...], --input INPUT [INPUT ...]
                        Input GenBank files or directories (default: None)
  -o OUTPUT, --output OUTPUT
                        Output directory (default: .)
  -m METADATA_OUTPUT, --metadata-output METADATA_OUTPUT
                        Metadata table (one row per record) (default:
                        metadata.csv)
  -a ASSEMBLY_OUTPUT, --assembly-output ASSEMBLY_OUTPUT
                        Assembly / sequencing data table (default:
                        assembly.csv)
  -f FINAL_OUTPUT, --final-output FINAL_OUTPUT
                        Metadata and assembly data merged (default: final.csv)
  --stream, --no-stream
                        Stream processing (default; same results, less memory
                        on large inputs) (default: True)
  --batch               Batch mode (parallel) (default: False)
  --max_tasks MAX_TASKS
                        Parallel processes in --batch mode (default: 4)
  --log_interval LOG_INTERVAL
                        Log progress every N records (0 = never) (default:
                        5000)
  --metadata_delimiter METADATA_DELIMITER
                        Column delimiter of the metadata table (default: ,)
  --assembly_delimiter ASSEMBLY_DELIMITER
                        Column delimiter of the assembly table (default: )
  --final_delimiter FINAL_DELIMITER
                        Column delimiter of the merged table (default: ,)
  --only_assembly_meta, -oam
                        Extract only the assembly / sequencing data (default:
                        False)
  --only_except_assembly_meta, -oeam
                        Extract only the metadata (no assembly data) (default:
                        False)
  --update_taxonomy     Update the local ete3 NCBI taxonomy database first
                        (default: False)
  --no_report           Do not write extraction_report.json and the error
                        table (default: False)
  --no_tracking         Do not write the per-record tracking table (default:
                        False)
  --no_recursive        Do not search subdirectories of the inputs (default:
                        False)
  --if_use_chunksize    (Legacy) same as --stream (default: False)
```
