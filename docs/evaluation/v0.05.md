# 测评：v0.05 的默认流程（rRNA 按序列归类 + 污染提示）

[← README](../../README.md) · [rRNA 区段评估](rdna-regions.md) · [污染提示评估](screen.md)

v0.05 的 `g2t` 默认：

- **第 2b 步：** 12S、16S、18S、5.8S、28S、ITS 按序列本身归类（`g2t-verify`）。序列结果与标题或注释不同时，以序列为准。
- **第 5 步：** 对每个标记做污染和鉴定错误提示（`g2t-screen`）。

`--no-verify --no-screen` 等同 v0.04，只按注释归类。下面用同一批记录，比较两种做法得到的“标本 × 基因”矩阵。测试日期 2026-11-13；机器为 16 核，但被其他任务占满，负载约 37。

## 1. 矩阵的变化

**Hesionidae（2,250 条记录，1,282 个标本）**

| 列 | 按注释（v0.04） | 按序列（v0.05） | 移出 | 移入 | 原因 |
|---|---|---|---|---|---|
| 12s | 29 | 24 | 5 | 0 | MG523356–60 标题写 "small subunit … mitochondrial"，序列整条是 16S，与已知 16S 记录 98–100% 相同 |
| 16s | 375 | 380 | 0 | 5 | 同上 |
| 18s | 211 | 202 | 9 | 0 | KP7455xx 等 ITS 记录只含 44–48 bp 的 18S 末端 |
| 28s | 257 | 254 | 3 | 0 | GQ426730–32 是 5.8S + ITS2，28S 只有末端一小段 |
| its1-its2 | 138 | 136 | 2 | 0 | OQ703007、OQ703012 标题写 "18S and ITS"，序列几乎全是 18S（1,588 bp 中 18S 占 2–1576） |
| coi、cob、h3、18-28s、mtgenome | — | 不变 | 0 | 0 | |

原有的冲突检查对这批数据报 0 个冲突：上述错误标题和注释写法一致，只看注释发现不了。

**Enchytraeidae（10,773 条记录）**

| 列 | 按注释（v0.04） | 按序列（v0.05） | 移出 | 移入 | 原因 |
|---|---|---|---|---|---|
| 18s | 1,128 | 312 | 816 | 0 | 标题写 "18S partial; ITS1, 5.8S, ITS2; 28S partial" 的 ITS 记录，只含 18S 引物端片段（最长 67 bp） |
| 28s | 1,691 | 339 | 1,352 | 0 | 同上，只含 28S 引物端片段 |
| its1-its2 | 1,886 | 1,886 | 0 | 0 | |
| coi、16s、12s、cob、h3、mtgenome | — | 不变 | 0 | 0 | |

- 标本数从 4,785 变为 4,781。变化来自移出 18S/28S 列的记录，未逐个核对。
- 按注释归类时，这些 ITS 记录同时占着 18S 和 28S 列，建 18S/28S 矩阵时会混进 ITS 序列。

**按序列归类的规则**

| 核验结论 | 处理 | Enchytraeidae | Hesionidae |
|---|---|---|---|
| agree：序列与注释一致 | 不变 | 3,218 | 780 |
| partly：注释的类型只有一部分被序列支持 | 改为序列支持的类型 | 1,479 | 14 |
| different：序列是另一种 rRNA | 改为序列的类型 | 0 | 5 |
| unverifiable：只有间隔区，没有 5.8S 可以定位 | 保留注释类型 | 18 | 105 |
| no_hit：短片段，模型找不到 | 保留注释类型（例：GU453353 是 175 bp 的 28S，只有 4.3 bits，没找到不等于不是 28S） | 12 | 0 |
| new：注释未归类，序列是 rRNA | 归入序列的类型 | 0 | 0 |

原注释结果保存在 `labeled_genes/*.annotation.csv`，每条记录都有 `annotation_type`、`sequence_type`、`verify_verdict` 三列，可以逐条对照。

## 2. 核验本身的准确度

详见 [rdna-regions.md](rdna-regions.md)。

- **12S、16S、18S、28S 的区分：** Enchytraeidae 中标题与 feature 一致的记录，各取 150 条（共 600 条），591 条与序列结果一致，12S、16S、18S 之间没有一条混淆。不一致的 9 条都是 175–378 bp 的 28S 短片段。
- **区段边界：** 近全长 18S/28S 与 Rfam 完整模型（cmscan）的边界一致（18S 60/60；28S 60/60，其中 59 条相差 ≤ 5 bp）。
- **加速前后对比：** 加速版与“每条记录跑全部完整模型”相比，5,654 条记录中只有 4 条结论不同，都是改进。

## 5. 线粒体基因组测序方法（`g2t-mitostats`）

v0.04 把没有 Assembly-Data 注释的记录一律记为 Unknown。但 NCBI 2012 年才有这个注释：150,025 条后生动物线粒体基因组中，2012 年以前提交的没有一条带它。

v0.05 改为：

- 论文标题写明高通量方法的，记为 NGS；
- 2012 年以前提交的，记为 Sanger（推断）；
- 其余仍为 Unknown。

`seq_basis` 列写明依据。

| 数据 | v0.04：Sanger / NGS / Unknown | v0.05：Sanger / NGS / Unknown |
|---|---|---|
| 后生动物，不含人类（81,592 条） | 6,544 / 47,797 / 26,231 | 11,015 / 48,419 / 21,138 |
| Annelida（745 条） | 55 / 512 / 173 | 68 / 512 / 160 |

v0.05 中，Unknown 全部是 2012 年以后提交的记录。

## 6. 局限

- 第 2b 步只核验 rRNA。COI 等蛋白基因的标题错误要靠第 5 步的距离提示发现，不做专门的类型核验。
- 第 2b 步需要 pyhmmer，Windows 上没有，会跳过。第一次运行要下载 barrnap 的线粒体模型；无网络时也跳过，并给出提示。
- 污染提示只依据距离，可能的原因还有：属本身不是单系、名称过时、近缘属共享单倍型。提示只表示值得核查，需要对照原文、标本和系统树判断。
